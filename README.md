# Orbit — The Scholar's Command Center

🔗 **Live Demo:** https://students-orbit.lovable.app/

Orbit is a futuristic, customizable **student productivity and academic management platform** designed for the **Recode Hackathon at Mukesh Patel School of Technology Management and Engineering (MPSTME)**.

Instead of using multiple disconnected platforms for tasks, resources, feedback, attendance, productivity, and well-being, Orbit brings everything together into one intelligent academic command center.

## Problem Statement

Students and professors often rely on multiple platforms to manage different aspects of academic life. This creates a fragmented experience where:

- Important deadlines are easily missed
- Students struggle to prioritize tasks
- Academic resources are scattered
- Professor feedback is difficult to track
- Attendance and academic progress are disconnected from productivity
- There is little connection between academic performance and student well-being

Orbit addresses this fragmentation by creating a unified system for managing and understanding academic life.

## Solution

Orbit consolidates academic management, productivity, resources, feedback, and well-being into a single customizable dashboard.

The platform is designed around three interconnected modes:

- **Student Individual Mode** — Personal productivity and learning management
- **Class Mode** — Subjects, lectures, attendance, academic performance, and resources
- **Teacher Mode** — Student monitoring, teaching, feedback, and guidance

## Key Features

### 1. Priority Hub — Task Gravity System

Tasks are prioritized using:

- **Urgency** — Based on deadlines
- **Academic Weight** — Based on marks/importance

This helps students focus on tasks with the highest academic impact.

### 2. Contextual UI Adaptation

The interface adapts according to the student's current context.

For example, during a live lecture, Orbit can switch to **Focus Mode**, displaying only relevant lecture tools, notes, and resources while minimizing distractions.

### 3. GitHub-Style Feedback System

Professor feedback is treated like trackable issues.

Students can:

- View feedback
- Respond to feedback
- Track improvements
- Mark issues as resolved

This transforms feedback into an actionable workflow.

### 4. Resource Shelf

A centralized academic resource library that allows students to:

- Search resources across subjects
- Filter by subject, type, and date
- Access PDFs and videos
- Organize learning materials in one place

### 5. Knowledge Graph

A visual knowledge graph connects subjects, topics, and concepts to encourage **concept-based learning** rather than isolated memorization.

### 6. Mental Health & Productivity Tracking

Orbit combines academic productivity with student well-being through:

- Mood tracking
- Journaling
- Focus tracking
- "Earn Focus" productivity system

### 7. Achievement Guidance System

Instead of simply displaying achievements, Orbit provides actionable guidance.

For example:

> "Attend 3 more lectures to reach 75% attendance."

This converts academic data into clear and achievable actions.

## Design Philosophy

Orbit follows a high-density dashboard approach that presents a large amount of information while maintaining clarity.

### Design Principles

- Minimal and professional interface
- High information density
- Glassmorphism-inspired UI
- Blue, black, white, and grey visual system
- Content-based typography hierarchy
- Modular dashboard panels
- Draggable and customizable components
- Command-based navigation

## Technology & Concepts

- Dashboard-based Information Architecture
- Single Page Application (SPA)
- Modular UI Components
- Task Priority Algorithms
- Knowledge Graph Visualization
- Context-Aware UI
- Interactive Resource Management
- Academic Data Visualization
- Responsive Web Design

## Hackathon

Orbit was designed for the **Recode Hackathon** at **Mukesh Patel School of Technology Management and Engineering (MPSTME)**.

The project focuses on rethinking how students interact with academic information by transforming scattered academic data into a unified and actionable experience.

## Vision

Orbit is more than a productivity dashboard.

It aims to become a **decision-making system for students** and a **guidance system for professors** — helping students understand what to focus on, when to focus, and how to improve.
